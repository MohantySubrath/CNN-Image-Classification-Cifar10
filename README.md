# CNN-Based Image Classification Using CIFAR-10

## Project Overview
This project implements an image classification system using a Convolutional Neural Network (CNN) and the CIFAR-10 dataset.

The project explores how CNNs can classify images into 10 different categories and how data augmentation can improve model generalization.

## Dataset
- Dataset: CIFAR-10
- Total images: 60,000
- Training images: 50,000
- Testing images: 10,000
- Image dimensions: 32 × 32 × 3
- Classes: Airplane, Automobile, Bird, Cat, Deer, Dog, Frog, Horse, Ship, Truck.

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Methodology
1. Load the CIFAR-10 dataset.
2. Preprocess and normalize images.
3. Apply data augmentation.
4. Build a CNN architecture.
5. Train the model.
6. Evaluate model performance.
7. Test predictions using sample images.

## CNN Architecture
The model uses convolutional layers, max-pooling layers, a flatten layer, dense layers, dropout, and a softmax output layer.
